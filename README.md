# EzSpy

一款受 Spy++ 启发的 Android 窗口检查工具：读取无障碍节点树，提取控件属性，并提供悬浮准星抓取模式。

- 语言：Kotlin
- UI：Material Design 2（黑灰主体 + 紫色强调，跟随系统浅色/深色）
- `minSdk` 26（Android 8.0），`targetSdk` 36（Android 16），`compileSdk` 37
- 包名：`com.udm.ezspy`
- 无网络权限；**不截图、不持久化、不上传任何数据**，仅在用户主动开始的抓取会话中读取，并只保存在内存里

## 功能

### 抓取器
空状态页提供「启用抓取器」、权限状态、当前会话状态和本次运行的隐私选项。权限不足时引导前往系统设置；权限就绪后：
1. 主界面自动最小化（`moveTaskToBack`）；
2. 显示悬浮球、准星、灰色选中框和可拖动的预览面板；
3. 按住悬浮球拖动准星，实时高亮并预览准星下的控件；
4. 悬浮球用红点、预览面板用「抓取中 · 已运行时间」提示当前是临时会话；
5. 主界面和预览面板都提供「停止」按钮；停止、超时或清除任务会立即移除悬浮窗并清空内存数据。

### 临时会话
- 一次会话默认最多 **3 分钟**，主界面可勾选「无限期抓取」关闭上限；
- 主界面显示会话状态（未在抓取 / 抓取中 / 已停止 / 已超时 / 已完成）和已运行时间；
- 抓取过程中重新打开主界面不会自动结束会话：主按钮保持禁用，主界面显示状态并保留「停止抓取」；预览面板仍在，完成并回节点树请点悬浮面板的返回箭头；
- 预览面板实时显示「抓取中 · 时间 / 上限」，返回箭头是「完成并查看」，旁边的「停止」直接丢弃；
- 只保留当前一次抓取，不做最近记录、导出、分享或云同步；
- 「停止」是丢弃：立即移除悬浮窗、清空 `SpyRepository` 和 `SpyViewModel`；
- 预览面板返回箭头：保留本次结果并回到主界面；
- 按返回键关闭主界面、从最近任务清除或无障碍服务被停用，也会结束会话并清空内存数据。

### 隐私选项（仅本次运行有效，重启后恢复默认）
- **显示敏感内容**：默认关闭。`node.isPassword == true` 的控件内容显示为 `••••`；勾选后才显示原文。节点树、属性栏、悬浮预览和「获取文本」都遵守该开关。
- **无限期抓取**：默认关闭；不勾选时 3 分钟自动停止并丢弃结果。
- **移除 FLAG_SECURE（允许截图）**：默认关闭。主界面默认带 `FLAG_SECURE`，避免节点内容进入最近任务缩略图、普通截图或录屏；需要截图时再勾选移除。
- 这些勾选项不会写入 SharedPreferences/DataStore，进程重启后回到安全默认值。

### 悬浮模式
- 球位置固定，只有准星跟随手指；
- 拖动过程中实时命中测试，松手保留选中框和预览，准星淡出消失；
- 命中的是准星下方的目标窗口，自动排除 EzSpy 自己的悬浮窗（穿透预览面板）；
- 预览面板只显示选中节点的摘要（类名、文本、ID、边界、包名），可滚动、可按住标题栏拖动；
- 预览面板可以拖到屏幕外（甚至完全移出）；移出后**点按悬浮球**即可把面板拉回默认位置；
- 返回键会保留当前选中信息并回到主界面；未选中任何控件时空白返回。

### 节点树
- 返回主界面后，显示所选控件所属窗口的**完整节点树**（先序遍历、全部节点，而不是只显示一条祖先链）；
- 顶部显示目标包名与节点总数；选中节点自动定位并居中，附带上下文与兄弟节点；
- 行高紧凑，层级缩进 20dp/层，带代码编辑器风格的竖向对齐线；
- 节点树页可水平平移查看深层节点；该页不再用左右滑动切换标签，改为点击标签切换（其他页仍可滑动）；
- 点击任意节点会选中它并跳转到属性栏。

### 属性栏
- 显示选中节点的全部可读取属性：基本信息、窗口、布局、状态、支持的操作、附加数据等；
- 「文本」一栏始终存在，没有文本时显示“无”；
- 「获取文本」：从当前节点开始遍历其整棵子树，把每个控件的文本/内容描述按先序、以单个换行连接，弹出一个带标题的可编辑文本框，可复制或继续编辑；
- 支持点击任意属性行复制其值；
- 未选中节点时为空状态。

## 权限

| 权限 | 用途 |
| --- | --- |
| 无障碍服务 (`BIND_ACCESSIBILITY_SERVICE`) | 读取窗口节点树和属性 |
| 悬浮窗 (`SYSTEM_ALERT_WINDOW`) | 悬浮球与预览面板 |
| `QUERY_ALL_PACKAGES` | 把包名解析为应用名 |

> 注意：应用被重新安装/覆盖安装后，系统可能会关闭无障碍服务，需要在系统设置中重新开启。

## 临时工具与后台行为

EzSpy 不再是“常驻监视器”：没有轮询看门狗，也不会在退出时强行杀进程或关闭无障碍服务。

- **有会话时**：悬浮球/预览面板可见，主界面和预览面板都有「停止」；完成并回节点树请点悬浮面板的返回箭头；3 分钟超时（或勾选无限期）后自动结束。
- **停止/超时/清除任务/返回关闭**：移除悬浮球、准星、选中框和预览面板，清空 `SpyRepository` 和 `SpyViewModel`。
- **无障碍服务**：由系统管理。没有抓取会话时服务可以保持启用，但不会主动读取或保存数据；如果不希望它继续启用，请到系统设置 → 无障碍中关闭 EzSpy。
- **不会自启动**：应用没有 `BOOT_COMPLETED`、JobScheduler、WorkManager、AlarmManager 或前台服务。已启用的无障碍服务由系统在开机后恢复，这是系统行为，不是应用主动启动。
- 如果 `onTaskRemoved` 没有送达，未勾选「无限期抓取」的会话最迟会被 3 分钟上限结束；勾选无限期时需要手动停止或关闭无障碍。已经结束的会话不会再采集。

> 说明：无障碍服务是系统绑定组件，应用无法保证“上滑后进程一定消失”。现在的设计目标是“没有会话就没有采集、数据只在内存、退出/超时即清空”，而不是通过 watchdog/杀进程制造假象。

## 构建

直接用 Android Studio 打开项目构建即可；也可以：

```bash
./gradlew :app:assembleDebug
```

## 代码结构

```
com.udm.ezspy
├── MainActivity.kt              // 标题栏 + TabLayout + ViewPager2
├── data/                        // NodeSnapshot、Capture、属性模型、会话状态、隐私开关、结果仓库
├── service/
│   ├── EzSpyAccessibilityService.kt
│   ├── OverlayController.kt     // 悬浮球/准星/高亮/预览面板
│   ├── NodeHitTester.kt         // 按屏幕坐标命中节点
│   ├── NodeSnapshotFactory.kt   // 节点快照 + 完整窗口树
│   └── overlay/                 // 自绘 Ball / Crosshair / Highlight
├── ui/
│   ├── grabber/                 // 抓取器页
│   ├── tree/                    // 完整节点树、对齐线、水平平移
│   ├── properties/              // 属性栏、文本提取
│   └── SpyViewModel.kt
└── util/                        // 权限、dp/屏幕尺寸
```

## 已知的 IDE 提示

- Android Studio 的 **Layout Validation** 对 `item_node_tree.xml` 可能提示 “title is covered by System UI”。该布局是 RecyclerView 的单行，并不是全屏页面；真实界面由 `MainActivity` 统一处理系统栏 insets，因此此提示属于单行预览的误报。
- `lint` 结果为 0 errors；仅保留一条 Gradle 版本更新提示（模板使用 Gradle 9.6.0，提示可升级到 9.8.2）。
